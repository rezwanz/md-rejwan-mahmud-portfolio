# Modern Portfolio Website Master Plan

## Recommended Stack

-   React + Vite
-   Tailwind CSS
-   Framer Motion
-   GSAP (light usage)
-   GitHub Pages deployment
-   Cloudflare custom domain

## Why

-   Fully static
-   Free hosting
-   Fast
-   SEO friendly
-   Easy maintenance
